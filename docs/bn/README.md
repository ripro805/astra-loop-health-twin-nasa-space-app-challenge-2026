# ASTRA-LOOP: সম্পূর্ণ বাংলা প্রজেক্ট গাইড ও ইন্টারভিউ নির্দেশিকা

স্বাগতম! এই ফোল্ডারটিতে **ASTRA-LOOP (NASA Space Apps Challenge 2026)** প্রজেক্টের সম্পূর্ণ বাংলা ডকুমেন্টেশন প্যাকেজ সাজানো রয়েছে। আপনি যদি কোডিং বা মহাকাশ চিকিৎসাবিজ্ঞান না-ও জেনে থাকেন, তবে এই গাইডগুলো পড়ে আপনি প্রজেক্টের প্রতিটি অংশ বুঝতে পারবেন এবং যেকোনো ইন্টারভিউ বা বিচারকদের সামনে আত্মবিশ্বাসের সাথে উপস্থাপন করতে পারবেন।
