# ASTRA-LOOP: কীভাবে চালাবেন ও সমস্যা সমাধান (Beginner Run Guide)
> **নথি ক্রম:** ০৪ | **বিষয়:** শূন্য থেকে প্রজেক্ট চালু ও ১৫+ সমস্যা সমাধান | **টার্গেট:** একদম নতুন ব্যবহারকারী

---

## এই অংশে যা শিখবেন
* আপনার কম্পিউটারে (Windows বা Mac) প্রজেক্টটি চালানোর জন্য কী কী সফটওয়্যার লাগবে।
* কীভাবে মাত্র ৩টি সাধারণ কমান্ড দিয়ে পুরো সিস্টেমটি লাইভ চালু করবেন।
* পরিবেশ কনফিগারেশন (`.env`) ফাইলের প্রতিটি লাইনের সহজ ব্যাখ্যা।
* কোনো ত্রুটি বা এরর দেখা দিলে দ্রুত ঠিক করার জন্য ১৫+ বাস্তব সমস্যার সমাধান টেবিল।
* ইন্টারনেট ছাড়াই কীভাবে সম্পূর্ণ অফলাইনে প্রজেক্ট চালাবেন।

## ১. যা যা আপনার কম্পিউটারে ইনস্টল থাকতে হবে

আপনার কম্পিউটারে নিচের দুটি জিনিস থাকলেই যথেষ্ট:
1. **Node.js (ভার্সন 18 বা 20 এলটিএস):** জাভাস্ক্রিপ্ট কোড চালানোর ইঞ্জিন।  
   * ডাউনলোড লিংক: [nodejs.org](https://nodejs.org) (LTS ভার্সন ডাউনলোড করে সাধারণ সফটওয়্যারের মতো 'Next', 'Next' দিয়ে ইনস্টল করুন)।
2. **Git (গিট):** কোড নামানো ও ম্যানেজ করার টুল।  
   * ডাউনলোড লিংক: [git-scm.com](https://git-scm.com).
3. **VS Code (ঐচ্ছিক কিন্তু চমৎকার):** কোড এডিটর।  
   * ডাউনলোড লিংক: [code.visualstudio.com](https://code.visualstudio.com).

> [!NOTE]
> **Docker বা PostgreSQL কি লাগবে?**  
> না! v2 আপগ্রেডে আমরা পুরো ডাটাবেজ সিস্টেমটিকে **SQLite (`file:./dev.db`)** এ রূপান্তর করেছি। এটি একটি একক ফাইলের মধ্যে সম্পূর্ণ ডাটাবেজ চালিয়ে দেয়। তাই কোনো ডকার বা আলাদা ডাটাবেজ ইনস্টল করার ঝামেলা নেই!

## ২. প্রজেক্ট সেটআপ: ধাপে ধাপে নির্দেশিকা

### ধাপ ১: টার্মিনাল বা কমান্ড প্রম্পট খুলুন
* **Windows-এ:** কিবোর্ডে `Win + R` চেপে `cmd` অথবা `powershell` লিখে এন্টার দিন।
* **Mac-এ:** `Command + Space` চেপে `Terminal` লিখে এন্টার দিন।

প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
cd D:\KnowledgeVault\Project\astra-loop-health-twin-nasa-space-app-challenge-2026
```

### ধাপ ২: প্রয়োজনীয় প্যাকেজগুলো ইনস্টল করুন
এই কমান্ডটি প্রজেক্টের সমস্ত লাইব্রেরি নামিয়ে নেবে:
```bash
npm install
```
*(এক লাইনে ব্যাখ্যা: এটি ইন্টারনেটের এনপিএম স্টোর থেকে প্রজেক্টের প্রয়োজনীয় সব লাইব্রেরি ডাউনলোড করে `node_modules` ফোল্ডারে সাজিয়ে রাখে।)*

### ধাপ ৩: ডাটাবেজ তৈরি ও ডেমো ডেটা ভরুন (Seeding)
প্রজেক্টের ডাটাবেজ ফাইল ও ৯০ দিনের অ্যাস্ট্রোনট ডেটা তৈরি করতে নিচের কমান্ড দুটি দিন:
```bash
npm run prisma:generate -w apps/api
npm run prisma:push -w apps/api
npm run seed -w apps/api
```
*(এক লাইনে ব্যাখ্যা: এটি একটি নতুন `dev.db` ডাটাবেজ ফাইল তৈরি করে এবং কমান্ডার অ্যালেক্স ও ড. মায়ার ৯০-১২০ দিনের মহাকাশ স্বাস্থ্য ডেটা লোড করে।)*

### ধাপ ৪: প্রজেক্ট রান করুন (সার্ভার চালু করা)
সব প্যাকেজ বিল্ড করে একসাথে চালাতে দিন:
```bash
npm run build -w packages/shared
npm run dev
```
*(এক লাইনে ব্যাখ্যা: এটি একসাথে ব্যাকএন্ড মিশন কন্ট্রোল এপিআই এবং ফ্রন্টএন্ড নেক্সট.জেএস ওয়েব ড্যাশবোর্ড চালু করে দেয়।)*

### ধাপ ৫: ব্রাউজারে অ্যাপ খুলুন
আপনার পছন্দের ব্রাউজার (Chrome, Edge বা Brave) খুলে নিচের লিংকে যান:
* **প্রধান ড্যাশবোর্ড (Web UI):** [`http://localhost:3000`](http://localhost:3000)
* **মিশন কন্ট্রোল ব্যাকএন্ড এপিআই:** [`http://localhost:4000`](http://localhost:4000)

অভিনন্দন! আপনার লোকাল এস্ট্রোনট ডিজিটাল টুইন এখন পুরোপুরি সচল!

## ৩. কনফিগারেশন ফাইল (`.env`)-এর সহজ অর্থ

প্রজেক্টের মূল ফোল্ডারে একটি লুকানো ফাইল থাকে যার নাম `.env`। এটি মূলত অ্যাপের সেটিং বা চাবি:

```env
# ডাটাবেজ কানেকশন স্ট্রিং (আমাদের সেলফ-কন্টেইন্ড SQLite ফাইল)
DATABASE_URL="file:./dev.db"

# ব্যাকএন্ড এপিআই সার্ভার কোন পোর্টে চলবে
PORT=4000
API_PORT=4000
NODE_ENV=development

# ফ্রন্টএন্ড কোথা থেকে ডেটা নেবে
NEXT_PUBLIC_API_URL="http://localhost:4000/api"
```

* **`DATABASE_URL`:** অ্যাপটি জানে তার সব তথ্য এই `dev.db` ফাইলে জমা রাখতে হবে।
* **`PORT=4000`:** ব্যাকএন্ড সার্ভার কম্পিউটারের ৪০০০ নম্বর গেট দিয়ে ডেটা পাঠাবে।
* **`NEXT_PUBLIC_API_URL`:** ফ্রন্টএন্ড ওয়েব পেজটি জানে কীভাবে ৪০০০ নম্বর পোর্টের সাথে কথা বলতে হবে।

## ৪. সমস্যা সমাধান নির্দেশিকা (Troubleshooting — ১৫+ বাস্তব সমস্যা)

| ক্রম | যে ত্রুটি বা এরর দেখতে পারেন | কারণ কী? | কীভাবে সমাধান করবেন (Step-by-Step Fix) |
| :---: | :--- | :--- | :--- |
| **১** | `Error: listen EADDRINUSE :::3000` | ৩০০০ নম্বর পোর্টটি অন্য কোনো সফটওয়্যার আগে থেকেই ব্যবহার করছে। | টার্মিনালে লিখুন: `npx kill-port 3000` অথবা কম্পিউটার রিস্টার্ট দিন। |
| **২** | `Error: listen EADDRINUSE :::4000` | এপিআই সার্ভার আগে থেকেই ব্যাকগ্রাউন্ডে চলছে। | টার্মিনালে লিখুন: `npx kill-port 4000` দিয়ে আবার `npm run dev` দিন। |
| **৩** | `PrismaClientInitializationError` | প্রিজমা ক্লায়েন্ট তৈরি করা হয়নি বা ডাটাবেজ ফাইল রিড করা যাচ্ছে না। | টার্মিনালে চালান: `npm run prisma:generate -w apps/api`। |
| **৪** | `Cannot find module '@astra-loop/shared'` | শেয়ার্ড লাইব্রেরিটি এখনও বিল্ড করা হয়নি। | চালান: `npm run build -w packages/shared`। |
| **৫** | `Script execution policy error` (Windows) | উইন্ডোজ পাওয়ারশেল স্ক্রিপ্ট রান করার পারমিশন ব্লক করছে। | পাওয়ারশেল অ্যাডমিন হিসেবে খুলে লিখুন: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`। |
| **৬** | ড্যাশবোর্ড লোড হয়েছে কিন্তু ডেটা আসছে না (ফাঁকা) | ব্যাকএন্ড এপিআই সার্ভার চালু নেই বা ক্র্যাশ করেছে। | টার্মিনালে চেক করুন এপিআই সার্ভার `localhost:4000` এ রানিং আছে কি না। |
| **৭** | `SQLite file is locked` | দুটি টার্মিনালে একসাথে ডাটাবেজ রাইট করার চেষ্টা চলছে। | অতিরিক্ত টার্মিনালগুলো বন্ধ করে শুধু একটি টার্মিনালে চালান। |
| **৮** | `Failed to fetch / CORS error` | `.env` ফাইলে এপিআই ইউআরএল ভুল আছে। | নিশ্চিত করুন `NEXT_PUBLIC_API_URL="http://localhost:4000/api"` লেখা আছে। |
| **৯** | `node: command not found` | কম্পিউটারে Node.js ইনস্টল নেই বা পাথ সেট করা নেই। | [nodejs.org](https://nodejs.org) থেকে ইনস্টল করে টার্মিনাল রিস্টার্ট দিন। |
| **১০** | `npm run seed` এ এরর দিচ্ছে | ডাটাবেজ স্কিমা পুশ না করে সিড রান করা হয়েছে। | আগে লিখুন `npm run prisma:push -w apps/api` তারপর সিড দিন। |
| **১১** | `next: command not found` | ডিপেন্ডেন্সি ঠিকমতো ডাউনলোড হয়নি। | টার্মিনালে লিখুন: `npm install`। |
| **১২** | পেজে কোনো সিএসএস স্টাইল নেই (সাদাকালো দেখাচ্ছে) | টেইলউইন্ড সিএসএস বিল্ড হয়নি বা ক্যাশ জমেছে। | `.next` ফোল্ডারটি ডিলিট করে দিন এবং পুনরায় `npm run dev` দিন। |
| **১৩** | মোবাইলে স্ক্রিন ভেঙে যাওয়া | ব্রাউজার জুম ২০০% করা আছে। | কিবোর্ডে `Ctrl + 0` চেপে ব্রাউজার জুম ১০০% করুন। |
| **১৪** | `OutOfMemoryError` أثناء বিল্ড | কম্পিউটারের র‍্যাম পূর্ণ হয়ে গেছে। | অপ্রয়োজনীয় অ্যাপ বন্ধ করুন এবং চালান: `NODE_OPTIONS="--max-old-space-size=4096" npm run build`। |
| **১৫** | গিট স্ট্যাটাসে অতিরিক্ত ফাইল দেখাচ্ছে | বিল্ড আউটপুট ট্র্যাক হয়ে গেছে। | টার্মিনালে চালান: `git status` এবং `.gitignore` আপডেট রাখুন। |

## ৫. ডেমো কন্ট্রোল ও টেস্ট করার শর্টকাট

অ্যাপের ভেতরে একটি গোপন কিন্তু চমৎকার ডেমো কন্ট্রোল প্যানেল আছে। এটি বিচারকদের সামনে লাইভ ড্রামা দেখানোর জন্য সেরা:

1. **যেকোনো দিনে জাম্প করা:** ড্যাশবোর্ডে গিয়ে আপনি মিশন ডে ৬০, ৬১ বা ৬৫ সিলেক্ট করতে পারেন।
2. **সৌর ঝড় ট্রিগার করা (Solar Flare):** ডেমো প্যানেলে **"Trigger Solar Storm"** বাটন চাপলে লাইভ রেডিয়েশন সেন্সর স্পাইক করবে এবং পুরো ড্যাশবোর্ড লাল অ্যালার্ট দেখাবে।
3. **উচ্চ রক্তচাপ তৈরি করা (Raise BP):** **"Simulate BP Spike"** চাপলে সিস্টোলিক রক্তচাপ ১৬৫ হয়ে যাবে এবং ডুয়াল-লেয়ার এসকেলেশন ব্যানার জ্বলে উঠবে।
4. **কেবিনে কার্বন ডাই-অক্সাইড স্পাইক:** **"Spike CO2"** চাপলে কেবিন $\text{CO}_2$ লেভেল ৬০০০ ppm এ চলে যাবে এবং মাথা ব্যথার উইজার্ড চালু হবে।
5. **সবকিছু রিসেট করা:** **"Reset to Day 1"** চাপলে ডাটাবেজ আবার স্বাভাবিক শুরুতে ফিরে যাবে।

## ৬. ইন্টারনেট ছাড়া সম্পূর্ণ অফলাইনে কীভাবে চালাবেন?

যদি পরীক্ষার হলে বা ইন্টারভিউতে কোনো ওয়াইফাই বা ইন্টারনেট না থাকে:
1. ল্যাপটপে প্রজেক্টটি একবার রান করে রাখুন।
2. আপনার ফোনের হটস্পট বা ওয়াইফাই ডিসকানেক্ট করে দিন।
3. ব্রাউজারে [`http://localhost:3000`](http://localhost:3000) এ যান।
4. আপনি দেখতে পাবেন অ্যাপটি **এক সেকেন্ডের জন্যও আটকাবে না!** কারণ এর ব্যাকএন্ড, লোকাল ডাটাবেজ, ম্যাথ ইঞ্জিন এবং অফলাইন ইনডেক্সড-ডিবি সম্পূর্ণভাবে আপনার ল্যাপটপের ভেতরেই কাজ করে। বিচারকদের সামনে এটিই আমাদের সবচেয়ে বড় প্রমাণ যে আমরা আসলেই মহাকাশের জন্য অফলাইন সিস্টেম বানিয়েছি!
